fix(cosem)!: align IC 62 Compact Data class version with ED4

IEC 62056-6-2 ED4 (2021) §4.3.10 / DLMS UA Blue Book Ed. 12.1
define the Compact Data IC at class_id 62, version 1 with five
attributes (1 logical_name, 2 buffer, 3 capture_objects,
4 template_id, 5 template_description, 6 capture_method) and two
specific methods (1 reset, 2 capture).

The attribute and method layout in `CosemCompactDataObject`
already matched the spec, but `MaxSupportedVersion` was still
`0` (the obsolete legacy version), so the descriptor and
`AccessRights` advertised version `0` and the default
constructor pinned objects to that version.

Bump `MaxSupportedVersion` to `1`, default the short
constructor to version `1`, and update the
`ExposesAllAttributes` test to expect `key.version == 1`.
Refresh the COSEM IC support matrix and COSEM API guide to
describe Compact Data as class version `1` per
IEC 62056-6-2 ED4 §4.3.10.

Tests: dlms_cosem_tests 276/276, full ctest 937/937.

BREAKING CHANGE: `CosemCompactDataObject` now advertises class
version `1` instead of `0` over the wire. Clients that pinned
the descriptor / `AccessRights` to version `0` must be updated.
The constructor signatures are unchanged.
