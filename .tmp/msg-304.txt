refactor(cosem)!: rebuild IC 77 M-Bus Diagnostic to IEC ED4 layout

IEC 62056-6-2 ED4 (2021) §4.8.7 defines IC 77 (M-Bus
Diagnostic, version 0) with 8 dynamic attributes plus
logical_name and an optional `1 reset` method. The prior
built-in object used a non-spec set of 6 attributes
(received_signal_quality, transmitter_signal_quality, bbc,
two FCS counters, capture_time) and reported MethodNotFound
for every method id. That mismatched the wire surface.

Rebuild the attribute layout and method dispatch to match the
spec:

- attr 2 = received_signal_strength (unsigned, dBm)
- attr 3 = channel_id (unsigned)
- attr 4 = link_status (enum)
- attr 5 = broadcast_frames_counter (array)
- attr 6 = transmissions_counter (double-long-unsigned)
- attr 7 = fcs_ok_frames_counter (double-long-unsigned)
- attr 8 = fcs_nok_frames_counter (double-long-unsigned)
- attr 9 = capture_time (date-time octet-string(12))
- method 1 `reset` (optional) -> UnsupportedFeature; the
  built-in object does not own the counter sources, so the
  backend must republish refreshed values via the attribute
  setters. Other method ids continue to return MethodNotFound.

Renamed C++ accessors accordingly
(`ReceivedSignalStrength`, `ChannelId`, `LinkStatus`,
`BroadcastFramesCounter`, `TransmissionsCounter`, plus the
existing FCS counters and `CaptureTime`).

Refreshed unit tests, COSEM IC support matrix, COSEM API
guide and COSEM test plan.

Tests: dlms_cosem_tests 277/277, full ctest 938/938.

BREAKING CHANGE: `CosemMBusDiagnosticObject` constructors now
take 8 buffer parameters in a new order
(received_signal_strength, channel_id, link_status,
broadcast_frames_counter, transmissions_counter,
fcs_ok_frames_counter, fcs_nok_frames_counter, capture_time)
and the accessor names changed
(`ReceivedSignalQuality`/`TransmitterSignalQuality`/`Bbc` are
removed). Reads of attributes 2..9 and writes of attributes
2..9 now map to the spec layout instead of the previous
6-attribute layout, and method id `1` now reports
`UnsupportedFeature` instead of `MethodNotFound`.
