fix(cosem)!: correct M-Bus Master Port Setup class_id 73 -> 74

IEC 62056-6-2 ED4 (2021) §4.8.5 (and the DLMS UA Blue Book
Ed. 12.1 §4.8.4) defines the M-Bus master port setup IC as
class_id 74, version 0 with the same two attributes
(1 logical_name, 2 comm_speed) and no specific methods. The
built-in `CosemMBusMasterPortSetupObject` was registered under
class_id 73, which is actually reserved for the Wireless Mode Q
channel IC.

- Change `kMBusMasterPortSetupClassId` from 73 to 74.
- Update the `ExposesAllAttributes` test to assert
  classId == 74u.
- IC support matrix: split the old `74`-`76` "M-Bus classes"
  row, add an explicit "Wireless Mode Q channel"
  application-provided entry for `73`, and move the M-Bus
  Master Port Setup row to `74`.
- COSEM API guide: refer to IC `74` and IEC 62056-6-2 ED4
  §4.8.5.

Tests: dlms_cosem_tests 277/277, full ctest 938/938.

BREAKING CHANGE: `CosemMBusMasterPortSetupObject::Descriptor()
.key.classId` is now `74` instead of `73`. Anything that
selected this object by the old (incorrect) class_id `73`
must be updated to use `74`.
