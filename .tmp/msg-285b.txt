fix: align builtin s-fsk plc phy and mac setup with ed4 attribute table

Phase 285b. Phase 285 (commit 74ab4cb) added CosemSFskPlcPhyMacSetupObject
but used an attribute table that did not match IEC 62056-6-2 ED4 (2021)
section 4.10.3 / DLMS UA Blue Book Ed. 16 IC 50. The original layout
had 15 mutable attributes (2..16) with separate mark_frequency and
space_frequency fields and used legacy names "maxReceivedGain",
"maxTransmitGain", "searchInitiatorTimeout" and "minDeltaCredit". ED4
groups mark/space into a single `frequencies` structure attribute (id 7)
and uses the modern names "max_receiving_gain", "max_transmitting_gain",
"search_initiator_threshold" and "min_delta_credit", giving 14 mutable
attributes (2..15).

The fix renames the `Attributes` aggregate fields, merges
mark/space into a single `frequencies` opaque buffer, drops attribute
16, and re-routes Read/Write/AccessRights over the new 2..15 range. The
on-wire bytes a meter sees still depend on what the caller encodes;
this commit realigns the documented contract, the constants, the
switch-case routing and the sample test fixtures so consumers reading
the docs or copy-pasting the sample produce the ED4 layout.

Changes:
- lib/dlms-cosem/include/dlms/cosem/simple_objects.hpp: rename
  Attributes fields (maxReceivingGain, maxTransmittingGain,
  searchInitiatorThreshold, frequencies, minDeltaCredit); add a doc
  comment block describing the ED4 attribute table; keep
  MaxSupportedVersion = 1.
- lib/dlms-cosem/src/cosem/simple_objects.cpp: change
  kSFskPlcPhyMacSetupLastMutableAttributeId from 16 to 15; renumber
  ReadAttribute/WriteAttribute case labels (4..15 now map to the
  renamed fields with 7 -> frequencies); the AccessRights loop is
  unchanged because it iterates [first..last].
- lib/dlms-cosem/test/cosem/test_simple_objects.cpp
  (MakeSampleSFskPlcPhyMacSetup): rewrite to encode the new field set
  (search_initiator_threshold = 0x62, frequencies = structure {
  double-long-unsigned mark = 0x000012C0, double-long-unsigned space =
  0x00001800 }, transmission_speed = enum 0x03 per the Blue Book v1
  default); update the helper code that references the legacy field
  names.
- lib/dlms-cosem/test/cosem/test_simple_objects.cpp
  (CosemSFskPlcPhyMacSetupObject): update the per-attribute pointer
  table to walk 2..15, update the "AttributeNotFound on 16" check, and
  use the renamed `frequencies` field instead of `markFrequency` for
  the write-rejection round-trip.
- CHANGELOG.md (0.65.0 entry): describe the renamed fields, the
  merged `frequencies` structure, and the 2..15 attribute range.
- docs/ic_support_matrix.md (row IC 50): same field renames and
  structure description.
- lib/dlms-cosem/docs/01_cosem_api.md (S-FSK PLC PHY & MAC Setup
  paragraph): same field renames and structure description.
- lib/dlms-cosem/docs/03_cosem_test_plan.md (S-FSK PLC PHY & MAC
  Setup tests): describe the 2..15 attribute range and the
  `frequencies` structure.
