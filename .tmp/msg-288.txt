fix(cosem)!: remove phantom port_speed attribute from iec local port setup

IEC 62056-6-2 ED4 (2021) clauses 4.7.1 and 5.6.1, and DLMS UA Blue Book
Ed. 12.1 clause 4.7.1, define IC 19 (IEC local port setup) with exactly
nine attributes (1..9) in both versions 0 and 1, and no specific methods.
The previous CosemIecLocalPortSetupObject implementation surfaced an
extra port_speed enum at attribute id 10, gated to v1, which is not part
of the standard.

BREAKING CHANGE: both CosemIecLocalPortSetupObject constructors drop the
portSpeed parameter, and the PortSpeed() getter is removed. Callers must
drop the port_speed buffer from construction sites. Reads of attribute
10 now report AttributeNotFound; attributes 2..9 continue to honor the
caller-selected AttributeAccessMode. MaxSupportedVersion stays at 1,
and InvokeMethod still reports MethodNotFound for all method ids.

Updates the IC support matrix, COSEM API guide, COSEM test plan and
CHANGELOG to reflect the corrected attribute surface. Bumps VERSION to
0.68.0 to flag the breaking API change.

Full ctest: 930/930 pass.
