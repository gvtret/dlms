fix(cosem)!: rebuild IC 46 SMTP Setup to spec layout (attrs 1..6)

IEC 62056-6-2 ED4 (2021) §4.9.6 and DLMS UA Blue Book Ed. 12.1
§4.9.6 define the SMTP Setup IC (class_id 46, version 0) with
exactly six attributes:

  1 logical_name      (octet-string, RO)
  2 server_port       (long-unsigned, default 25)
  3 user_name         (octet-string)
  4 login_password    (octet-string)
  5 server_address    (octet-string)
  6 sender_address    (octet-string)

The previous `CosemSmtpSetupObject` mismodelled the IC: it
invented a non-spec `smtp_server` octet-string at id 2, shifted
every subsequent attribute down by one, used different names
(`sender` vs `sender_address`), and added a non-existent seventh
`receivers` array attribute. None of those match any published
edition of the Blue Book or IEC 62056-6-2.

Replace constants, ctor parameter list, member fields,
access-rights table, read/write switches and accessors with
the spec layout (`kSmtpSetup{ServerPort,UserName,LoginPassword,
ServerAddress,SenderAddress}AttributeId` at ids 2..6).
`ReadAttribute(7, ...)` now reports `AttributeNotFound`. Methods
stay absent — the IC defines none — so `InvokeMethod` still
returns `MethodNotFound` for every id.

Refresh the IC 46 tests: drop the `smtpServer`/`receivers`
fields from `SmtpSetupBuffers`, encode a sample `long-unsigned
587` `server_port`, an octet-string `"smtp.example.com"`
`server_address`, and an octet-string `"a@b.c"`
`sender_address`. The writable id set in
`MutableAttributesHonorAccessMode` is now `{2, 3, 4, 5, 6}`; the
`AttributeNotFound` probe in `ExposesAllAttributes` shifts from
id 8 to id 7.

Update the IC support matrix, COSEM API guide and COSEM test
plan to describe attributes 2..6 and the new mutable set.

Tests: dlms_cosem_tests 275/275, full ctest 936/936.

BREAKING CHANGE: `CosemSmtpSetupObject` constructors now take
five payload buffers in spec order
`(serverPort, userName, loginPassword, serverAddress,
senderAddress)` instead of the previous six
`(smtpServer, smtpServerPort, userName, loginPassword, sender,
receivers)`. The phantom `smtp_server` and `receivers`
attributes are gone; `SmtpServer()`, `SmtpServerPort()`,
`Sender()` and `Receivers()` accessors have been replaced with
`ServerPort()`, `ServerAddress()` and `SenderAddress()`.
Callers that previously addressed attribute ids `2..7` must
remap to `2..6` per the spec layout.
